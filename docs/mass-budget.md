# LR1600 mass budget

The current authoritative preliminary ledger is
[`config/hardware.yaml`](../config/hardware.yaml). It contains each item once,
including the fuselage group and removable gear. The derived configuration
report is [`analysis/mass/summary.json`](../analysis/mass/summary.json),
generated by [`scripts/cg_integration.py`](../scripts/cg_integration.py).

For the 2,600-g integration case, the wheel/FPV central estimate is **2539.5
g**, with a 2266.6--2852.4-g preliminary component-range screen. Skis are
2575.5 g and the central 45-g HD recording option is 2584.5 g. This is not a
measured-aircraft mass or a flight release; see
[`cg-integration-v2.md`](cg-integration-v2.md) for CG cases and battery
indexes.

Do not add fuselage hardpoints to gear mass, or wheel gear to the seasonal ski
mass: the ledger explicitly prevents both double counts. All construction and
commercial masses remain design estimates until components are weighed.
