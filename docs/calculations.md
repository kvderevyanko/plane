# LR1600 — исходная геометрия и расчётные нагрузки

Все величины здесь повторяют параметры `WingParameters` из
`scripts/generate_wing.py`. При изменении параметров запустите генератор и
пересмотрите этот документ: формулы ниже являются контрольным расчётом, а не
заменой прочностного анализа.

## Геометрия

| Величина | Формула | Значение |
| --- | --- | ---: |
| Размах `b` | задано | 1600 mm (1.600 m) |
| Полуразмах/консоль | `b / 2` | 800 mm |
| Корневая хорда `Cr` | задано | 250 mm |
| Концевая хорда `Ct` | задано | 200 mm |
| Сужение `λ` | `Ct / Cr` | 0.800 |
| Площадь крыла `S` | `b × (Cr + Ct) / 2` | 0.3600 m² (36.00 dm²) |
| Средняя аэродинамическая хорда (MAC) | `(2/3) × Cr × (1 + λ + λ²) / (1 + λ)` | 225.93 mm |
| Удлинение `AR` | `b² / S` | 7.11 |
| V одной консоли | задано | 2.0° |
| Подъём законцовки от V | `800 × tan(2°)` | 27.94 mm |
| Washout законцовки | задано | −1.5° |

Площадь — плановая площадь полного крыла, без поправки на V, зазоры, элероны
или законцовочные детали.

## Нагрузка

Исходная масса: `m = 2.4 kg`; принятое ускорение свободного падения:
`g = 9.80665 m/s²`; расчётная перегрузка: `n = 4`.

| Величина | Формула | Значение |
| --- | --- | ---: |
| Полётный вес | `m × g` | 23.54 N |
| Полная расчётная подъёмная сила | `m × g × n` | 94.14 N (≈9.60 kgf) |
| На одну консоль при симметричной нагрузке | `L / 2` | 47.07 N (≈4.80 kgf) |
| Расчётная нагрузка на площадь крыла | `L / S` | 261.5 N/m² (≈26.67 kgf/m²) |
| Номинальная нагрузка на площадь | `m / S` | 6.67 kg/m² |

Для первичной оценки, если считать распределённую по полуразмаху нагрузку
равномерной, изгибающий момент в корне **одной** консоли равен
`(L / 2) × 0.8 / 2 = 18.83 N·m`. Это только нижний контрольный ориентир:
реальное распределение подъёмной силы, масса консоли, манёвры, порывы,
посадка и концентрации в узле стыка требуют отдельной проверки.

## Лонжерон

Первоначальная ось главного лонжерона задана на `30 %` местной хорды. Это
75.0 mm от передней кромки у корня и 60.0 mm у законцовки. Посадочное отверстие
в каждой нервюре — круг Ø14.50 mm: наружный Ø14.00 mm трубы плюс
радиальный технологический зазор 0.25 mm. Центр расположен на средней линии
профиля; он автоматически меняется с хордой и twist.

Это не подтверждает прочность карбоновой трубы 14×12 mm или стыка консолей.
Прочностной расчёт трубы, фанерных усилений, вклейки и узла разъёма остаётся
обязательным до изготовления.
