# Рабочая папка

Этот каталог (`/home/kirill/codex/plane`) — единственное место для рабочих
файлов проекта: исходного кода, данных, документации, скриптов, конфигурации,
загруженных portable-инструментов и временных материалов, которые нужны для
воспроизводимой работы.

Правила для агентов:

- Создавать и изменять файлы, каталоги, локальные окружения и загружаемые
  приложения только внутри этого каталога. Не создавать проектные каталоги в
  `~/codex`, `~/Applications`, `/opt`, `/usr/local` или других местах без
  отдельного явного разрешения пользователя.
- Хранить в репозитории всё, что потребуется после публикации на GitHub или
  переноса проекта на другую машину.
- Необязательные программы, локальные зависимости, кэши, сборочные результаты,
  учётные данные и машинно-зависимые настройки не коммитить; добавлять их в
  `.gitignore`.
- Если без локального инструмента можно обойтись, не добавлять его в проект.

## Правила LR1600 CAD

- Базовая единица всех геометрических величин — миллиметр (`mm`).
- Не менять аэродинамические параметры и материалы из `config/aircraft.yaml`
  без отдельного решения пользователя.
- Параметрическая исходная модель и конфигурация являются source of truth;
  файлы из `build/` вручную не править.
- Не добавлять компенсацию kerf в исходную CAD-геометрию. Kerf задаётся только
  на производственном этапе.
- Существенные инженерные решения документировать в `docs/`.
- Перед изменением размеров крыла пересчитывать площадь, MAC и нагрузку.
- Перед выпуском файлов для физического производства запускать автоматические
  проверки. Успешный экспорт DXF сам по себе не означает готовность к резке.
