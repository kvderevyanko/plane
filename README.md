# LR1600 — FPV aircraft CAD project

Параметрический проект самолёта LR1600. Базовая единица геометрии — миллиметр.
Существующая проработка крыла находится в `design/`, `data/`, `generated/` и
`docs/wing.md`; универсальный CAD toolchain — в `cad/`.

## Быстрый запуск

```bash
./tools/build.sh
./tools/test.sh
```

Команды используют локальное окружение `.tools/conda/lr1600-cad` и создают
только воспроизводимые файлы в `build/`. Если окружение ещё не создано, см.
`environment/README.md`.

Перед физическим производством прочитайте `docs/laser-workflow.md` и выполните
проверки. Успешный экспорт не является разрешением на резку.
